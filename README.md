# Billova Retail

Professional Billing & Retail Management System

## Features
- Fast POS Terminal & Barcode Scanning
- Customer & Udhar (Credit) Management
- Vendor Management & Purchase Orders
- Multi-channel Payment Splits (Cash, UPI, Card)
- Live AI Business Intelligence (Groq AI)
- Cloud Backup & Multi-device Sync via Supabase
- Thermal Receipt & Label Printing

## Backend Setup
Configure your `.env` file with your Supabase credentials:
```env
SUPABASE_URL=https://auqapthcohowhjcchnia.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```
